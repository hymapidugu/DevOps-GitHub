# Git Commands



**Summary:**

This Document outlines the list of git commands which has been discussed till now  in Devops git & github.


No | Git Command | Description |
---|-------------|-------------|
1  | git clone   | Helps to connect with your VCS and SCM Repo|
2  | git init    | Helps to initialize the git repository|
3  | git add     | Helps to add your local file into stagging|
4  | git commit  | To commit the files from stagging to remote repo|
5  | git push    | Helps  to push your file into remote repo|


For more commands check out the [link](https://git-scm.com/cheat-sheet)
